# Демонстрация ZiyatAI без аренды сервера

[Замер семи локальных сервисов](reports/runtime-resources.json) после проверок показывает около 1 ГБ RAM только у антивируса. Это отдельный моментальный замер, не максимум и не расчёт production мощности; он объясняет, почему полный текущий стек не заявляется совместимым с лимитом 0,5 ГБ на службу в Railway Free.

На уже настроенном компьютере владельца дважды нажмите `Start demo.cmd` в корне проекта. Он запускает Docker Desktop и существующие сервисы, применяет локальные настройки, ждёт готовности и открывает сайт. Данные и тома не удаляются. Через терминал: `powershell -File scripts/start-demo.ps1 -OpenBrowser`.

Адреса:

- Сайт: http://localhost:3000
- Лёгкая версия: http://localhost:3000/lite/
- Демонстрационный почтовый ящик: http://localhost:8025

Это адреса самого компьютера. Для первого запуска на другом ПК сначала выполните настройку из README: Docker Desktop, Node.js, локальное окружение, БД/хранилище, миграции и образы приложения/renderer. Скрипт намеренно сообщает об отсутствующих сервисах, а не создаёт новый пустой комплект поверх неизвестных данных.

## Сценарий показа

До входа покажите гостевую главную, переключение тем и интерактивные примеры по предметам.

1. Зарегистрируйте демонстрационного учителя, выберите предмет и подтвердите шестизначный код из Mailpit. Mailpit показывает локальные тестовые письма; это не отправка на внешнюю почту.
2. Загрузите обезличенный КТП, выберите язык документа и дождитесь извлечения. Для Excel с несколькими классами выберите нужный лист.
3. Проверьте тему, текст целей и класс. Если даты не нужны, нажмите «Пропустить все даты»: действие работает на всех листах и страницах, его можно отменить до сохранения. Затем подтвердите план.
4. Если ключ OpenAI настроен — создайте задания. Иначе используйте явно отмеченный синтетический образец. Образец не выдаётся за генерацию AI.
5. Прочитайте задания, ответы и критерии. При необходимости отредактируйте и сохраните. Отметьте проверку и нажмите «Одобрить задания». После этого подготовьте DOCX/PDF. Готовые файлы появятся в библиотеке; после изменения заданий нужно одобрить новую версию.

Для OpenAI заполните `OPENAI_API_KEY` в **`.env.local`**, сохраните файл и снова запустите демонстрацию. Модель задаётся серверной переменной `OPENAI_MODEL`; ключ не нужно отправлять в чат или вводить в профиль учителя. Запросы API оплачиваются отдельно от хостинга.

Перед показом не выключайте ПК и Docker. Windows 7 рассматривается как клиент в браузере, а не как сервер Docker. На старых браузерах открывается Lite, без React и внешних шрифтов.

## Как показать по интернету

Бесплатный временный туннель может дать HTTPS-ссылку на локальный сайт, но это отдельная конфигурация: публичный `APP_URL`, безопасные cookies/Origin, передача файлов и обратные ссылки входа должны совпасть. Простое туннелирование `localhost:3000` без этих настроек не считается рабочим размещением. Базу, S3 и Mailpit наружу открывать не нужно. Туннель завершается вместе с процессом или компьютером; постоянный адрес и доступность не гарантируются. [Ограничения Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

## Railway и другие варианты

Условия проверены **16 октября 2026**. [Railway Free](https://railway.com/pricing) даёт $5 на первые 30 дней, затем $1 кредита в месяц, до 0,5 ГБ RAM на сервис и 0,5 ГБ тома. После trial в проекте допускается до трёх сервисов. Текущий ZiyatAI включает web, worker, БД, приватное хранилище, renderer/OCR и антивирус. Одному ClamAV в локальном простое нужен примерно 1 ГБ RAM; это измерение текущего ПК, а не универсальная оценка. Размещать весь этот комплект на Railway Free без изменения требований нельзя обещать.

Удаление Docker не отменяет потребность в памяти, БД и обработке документов. Для сегодняшней демонстрации выбран существующий ПК с Docker; для постоянной эксплуатации — сервер или оплачиваемый набор управляемых сервисов после расчёта бюджета и выбора региона хранения. Netlify может разместить фронтенд, но не заменяет остальные компоненты.

Хостинг не оплачен, публичный адрес и внешняя доставка писем пока не подключены.
