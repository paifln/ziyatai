# 003 — Лёгкий кабинет и воспроизводимая демонстрация

Дата: 16 октября 2026 года. Статус: принято для локальной демонстрации.

Кабинет использует один набор CSS токенов, локальный Onest и отдельные модули загрузки, генерации, профиля и списка планов. Общие компоненты отвечают за ошибки формы, пароль и подтверждение действий. Поля сохраняют семантику HTML, но формы отключают браузерные всплывающие ошибки и показывают связанные с полями сообщения. Lite остаётся отдельным ES5 клиентом с системным шрифтом; React и web fonts ему не нужны.

HTML основного кабинета получает случайный CSP nonce на каждый запрос через Next.js 16.4 proxy. Root layout читает headers, поэтому его страницы динамические; их нельзя безопасно раздавать как общий статический HTML с одним nonce. Скрипты разрешены только с nonce или своего origin; production не использует script unsafe-inline/unsafe-eval. Статический Lite использует внешние скрипты своего origin. Inline styles оставлены для существующих React настроек оформления. Передача публичного upload origin при сборке обязательна для CSP и прямой загрузки.

JSON ограничивается по фактически прочитанным bytes, включая chunked запросы; auth — 64 KiB. Multipart имеет отдельный предел и два одновременно буферизуемых запроса на web процесс. Это локальный предел процесса, а не распределённый rate limiter. Антивирус, quarantine и изолированный renderer сохраняются. Проверки UI не заменяют серверные проверки.

Для текущего показа выбрана существующая Docker среда на компьютере владельца. `Start demo.cmd` запускает только службы ZiyatAI, переносит игнорируемые настройки и проверяет готовность. Docker нужен компьютеру, который обслуживает приложение; школьный компьютер открывает сайт в браузере. Удаление Docker не устраняет PostgreSQL, storage, почту, OCR и LibreOffice.

Railway подходит для дальнейшего эксперимента, но бесплатный тариф не обещает вместить этот полный стек: после пробного кредита остаётся $1 в месяц, а лимиты памяти и числа служб ограничены. Netlify/Vercel могут обслуживать web часть, но не заменяют длительный worker и renderer. Публичная демонстрация требует доступного backend и HTTPS; временный туннель не считается production запуском. Подробности и проверенные ссылки — в [demo.md](../demo.md). Новые платные услуги и публичное размещение пока не создавались.

Для живой демонстрации выбрана GPT-5.4 mini с Responses и строгой схемой. Автоматические проверки на синтетических примерах проверяют структуру, уровни, баллы, ссылки, переводы и время отдельно по уровню. Они не заменяют педагогическую экспертизу, и результат остаётся на проверке учителя. Полный набор из 36 сценариев не объявляется пройденным по нескольким успешным вызовам.
