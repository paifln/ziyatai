# Подключение настоящих сервисов

Код подтверждения теперь состоит из 6 цифр, действует 10 минут, имеет лимит попыток и повторной отправки. В локальном окружении доставка идёт в Mailpit. Это не доставка на Gmail/Mail.ru.

На экране ввода кода и восстановления пароля локальная демонстрация показывает **«Открыть тестовую почту»** — [Mailpit](http://localhost:8025). Это работает в основном интерфейсе и Lite на этом ПК. После подключения внешнего SMTP или при production-конфигурации подсказка не показывается. Публичный `/api/public-config` сообщает только один флаг, без настроек отправщика и секретов.

## OpenAI

Откройте `.env.local` в корне проекта. Внесите ключ в `OPENAI_API_KEY`, идентификатор доступной вам модели с Responses/structured output — в `OPENAI_MODEL`. Не вставляйте ключ в настройки учителя: это общий секрет сервера, не браузера.

Официальное создание ключа: https://platform.openai.com/api-keys. [Документация](https://developers.openai.com/api/docs/quickstart). API имеет отдельный биллинг; подписка ChatGPT не заменяет настройку API-проекта.

После изменения локального файла:

```powershell
powershell -File scripts/apply-local-settings.ps1
```

Команда переносит локальные параметры в исключённый из Git файл контейнеров и пересоздаёт web/worker, сохраняя БД и файлы. Операции генерации используют ключ только после этого. Для публичного сервера задайте те же переменные в его secret manager, а не в Netlify frontend build.

На компьютере владельца 16 октября проверена `gpt-5.4-mini`: запрос через Responses, генерация из подтверждённого плана, замена одного задания и экспорт. Для короткой проверки нового ключа без учебного документа можно выполнить `npx tsx --env-file=.env.local scripts/check-openai.ts`. Скрипт выводит только результат, модель и usage; ключ не печатает. Проверка делает небольшой платный API запрос. Настройте лимит расходов в своём OpenAI проекте.

## Почта

Нужен аккаунт транзакционной почты и подтверждённый отправитель. В `.env.local` замените `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` на выданные провайдером значения. Порт 465 использует TLS, 587 — STARTTLS. Запустите ту же команду применения настроек. В production TLS обязателен. Локальный Mailpit не является внешним провайдером.

Проверка подключения без отправки письма: `npx tsx --env-file=.env.local scripts/check-mail.ts`. После этого нужна регистрация с вашим внешним адресом и проверка получения кода, повторной отправки и ввода на настоящем домене. Сам SMTP handshake не доказывает доставку в папку «Входящие».

## Публичный адрес

Frontend подготовлен для Netlify, но OCR/worker/БД/файлам нужен отдельный контейнерный сервер. Регистрация в Netlify без backend не запустит весь продукт. Подробные команды: [Netlify](netlify.md), [сервер](deploy.md).

Нужны вход владельца в Netlify, доступ к серверу и аккаунту отправителя; Codex не может подтвердить владение вашей почтой или оплатить услуги от вашего имени. После авторизации настройку можно завершить по готовым конфигурациям. До этого нельзя объявлять проект публично работающим.

Перед публичной регистрацией заполните `LEGAL_OPERATOR_NAME` и `LEGAL_CONTACT_EMAIL`, уточните регион провайдеров и сроки резервных копий в политике. Юридические страницы сейчас описывают реализацию и явно показывают незаполненные сведения оператора. Эти два несекретных значения нужны при сборке: в Netlify задайте scope Build, на сервере Compose передаст их как build args. После изменения пересоберите frontend; обычного перезапуска контейнера для статической страницы недостаточно.

## Предметы

Справочник использует семейства предметов типовых учебных планов Казахстана (приказ №500), включая языки, математику, естественные и общественные науки, искусство и физкультуру. Это интерфейсный список, не утверждение, что все предметы обязательны для каждого класса. Для факультативов есть «Другой предмет».
