# Состояние перехода на Supabase

Текущие инструкции: [Supabase](supabase.md) и [README](../README.md). Авторизация использует email и пароль, регистрация сразу открывает кабинет без подтверждения. Прежний сценарий с кодами удалён.

В проекте установлены миграции 001–016 в приватную схему `ziyatai`, включена RLS и закрыт прямой доступ браузера. Создан приватный bucket `ziyatai-private`; база и файлы скопированы и проверены. Серверный реестр сессий обеспечивает немедленный отзыв доступа.

Текущая конфигурация приложения использует Supabase. Конфигурация и резервные копии находятся в игнорируемых локальных файлах. Старые пароли и сессии не переносились; импортированные материалы защищены от автоматического присвоения по email.

Публичный сайт https://ziyatai.netlify.app переключён на Supabase и текущий backend на ноутбуке. Готовность, регистрация без подтверждения в основной/Lite версиях, смена пароля, отзыв сеанса, загрузка из браузера, импорт и DOCX/PDF проверены через публичный адрес. Экспорт проверялся на явно помеченном синтетическом задании без AI. Дальнейшие обращения к AI остановлены по указанию владельца.

Старые локальные PostgreSQL/Garage/Mailpit и прежние worker остановлены; данные и резервные копии сохранены. Текущему backend нужны включённый ноутбук, Docker и интернет. Railway подготовлен отдельным пакетом, облачные ресурсы не создавались. Старые пароли не переносились; импортированные аккаунты требуют отдельного контролируемого переноса.
