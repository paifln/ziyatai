# Браузеры и адаптивность

Основной интерфейс предназначен для современных Chromium, Firefox и Safari. Для ограниченных школьных компьютеров предусмотрен `/lite/`: без React и Next.js runtime, с системными шрифтами и ES5-совместимым клиентским кодом. Автоматический выбор версии не заменяет обновление браузера и сертификатов ОС.

`npm run test:browser` запускает детерминированные проверки UI без подключения к пользовательской БД. Проверки авторизованного приложения находятся в `tests/e2e/`; им нужен запущенный backend и отдельные синтетические аккаунты. `QA_BASE_URL` задаёт адрес, `QA_BROWSER=webkit` выбирает установленный Playwright WebKit.

Проверяйте телефон и планшет в портретной и альбомной ориентации: отсутствие горизонтальной прокрутки всей страницы, доступность меню, полей, таблиц и кнопок, экранную клавиатуру, загрузку файла, длинные казахские/русские строки и обе темы. Viewport браузера не доказывает работу конкретного физического устройства.

В простое кабинет не опрашивает бизнес-API. Опрос включается для незавершённых операций и приостанавливается в скрытой/offline вкладке. Ошибка сети сохраняет правки и позволяет повторить действие явно.

`npx tsx scripts/checks/browser-check.ts` измеряет гостевые страницы и Lite при замедленной сети и CPU. Отчёты записываются в `.local/reports/`. Лабораторный результат не является статистикой production или обещанием скорости на всех школьных ПК.
